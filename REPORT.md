## 2. Мета роботи та досягнутий результат

Мета роботи — навчитися обробляти структуровані дані засобами Python, читати інформацію з CSV-файлів, перетворювати значення до відповідних типів, виконувати фільтрацію та агрегацію даних, обробляти помилки й формувати текстовий звіт.

У результаті роботи створено Python-пакет `project_tasks`, який:

- зчитує дані про проєктні задачі з CSV-файлу;
- перевіряє структуру та коректність вхідних даних;
- перетворює кількість годин на ціле число;
- нормалізує текстові значення;
- фільтрує задачі за статусом;
- обчислює кількість активних задач і загальну кількість годин;
- підраховує години за виконавцями;
- визначає унікальних виконавців;
- формує список задач із високим пріоритетом;
- записує результати в текстовий файл.

Для запуску програми реалізовано інтерфейс командного рядка (CLI). Для перевірки правильності роботи створено автоматизовані тести за допомогою `pytest`, налаштовано перевірки якості коду за допомогою `ruff` і автоматизацію перевірок через GitHub Actions.

## 3. Формат вхідних даних CSV

Вхідний файл: `data/tasks.csv`.

Файл містить інформацію про проєктні задачі. Поля розділяються комами.

Заголовок CSV-файлу:

```csv
name,assignee,hours,status,priority
```

Опис полів:

| Поле | Тип після обробки | Призначення |
|---|---|---|
| `name` | `str` | Назва задачі |
| `assignee` | `str` | Ім'я виконавця |
| `hours` | `int` | Кількість годин |
| `status` | `str` | Поточний статус задачі |
| `priority` | `str` | Пріоритет задачі |

Приклад рядка CSV:

```csv
Website design,Anna,5,in_progress,high
```

Після обробки цей рядок відповідає запису з такими значеннями:

- `name`: `"Website design"`
- `assignee`: `"Anna"`
- `hours`: `5`
- `status`: `"in_progress"`
- `priority`: `"high"`

Під час завантаження значення зчитуються за допомогою `csv.DictReader`. Файл відкривається в кодуванні UTF-8 із параметром `newline=""`. Текстові поля очищуються від зайвих пробілів, а статус і пріоритет приводяться до нижнього регістру. Кількість годин перетворюється з тексту на ціле число.

Якщо файл не містить заголовка або необхідних колонок, програма повідомляє про помилку. Якщо заголовок коректний, але рядків із задачами немає, завантаження повертає порожній список.

## 5. Перетворення даних: списки, словники, множини та включення списків

Для зберігання й обробки даних використовуються вбудовані структури Python.

**Список (`list`)** зберігає завантажені задачі. Кожна задача представлена словником із полями `name`, `assignee`, `hours`, `status` і `priority`.

**Словники (`dict`)** використовуються для представлення окремих задач і агрегування кількості годин за виконавцями. Ключем агрегованого словника є ім'я виконавця, а значенням — сумарна кількість годин.

**Множина (`set`)** застосовується для визначення унікальних виконавців без повторень.

**Включення списків (`list comprehensions`)** дають змогу компактно формувати списки на основі наявних даних і заданих умов. Наприклад, список задач із високим пріоритетом можна сформувати так:

```python
high_priority_tasks = [task for task in tasks if task["priority"] == "high"]
```

Для обчислення кількості годин за виконавцями можна накопичувати значення у словнику:

```python
hours_by_assignee = {}

for task in tasks:
    assignee = task["assignee"]
    hours_by_assignee[assignee] = hours_by_assignee.get(assignee, 0) + task["hours"]
```

У програмі використовуються такі типи даних:

- `str` — назви задач, виконавці, статуси та пріоритети;
- `int` — кількість годин і підраховані значення;
- `list` — список задач;
- `dict` — записи задач і результати агрегації;
- `set` — унікальні значення виконавців;
- `bool` — параметри керування фільтрацією.

## 6. Функції, аргументи за замовчуванням, `*args` і `**kwargs`

Логіку програми розділено на окремі функції, кожна з яких відповідає за певну дію.

Основні функції:

- `load_tasks(path)` — завантажує задачі з CSV-файлу;
- `analyze_tasks(tasks, include_done=False, *statuses, **options)` — аналізує та фільтрує задачі;
- функції модуля `reporting.py` — формують і записують текстовий звіт;
- `main()` — запускає програму через командний рядок.

У функції `analyze_tasks` використовуються три механізми передавання аргументів.

**Аргумент за замовчуванням**

```python
include_done = False
```

Якщо параметр не передано, задачі зі статусом `done` не включаються до основного аналізу.

**`*args`**

Параметр `*statuses` дає змогу передавати додаткові позиційні аргументи — статуси для фільтрації задач.

**`**kwargs`**

Параметр `**options` збирає додаткові іменовані аргументи у словник. Зокрема, можна передавати параметр `min_hours` для фільтрації за кількістю годин.

Приклад виклику:

```python
result = analyze_tasks(
    tasks,
    False,
    "todo",
    "in_progress",
    min_hours=3,
)
```

У цьому прикладі передаються статуси `todo` та `in_progress`, а також додаткова умова щодо мінімальної кількості годин.

## 7. Алгоритм обробки даних

Алгоритм роботи програми складається з таких етапів:

1. Отримати шляхи до CSV-файлу та вихідного текстового файлу з аргументів командного рядка.
2. Відкрити CSV-файл із кодуванням UTF-8.
3. Перевірити заголовок і наявність обов'язкових колонок.
4. Перевірити значення полів і перетворити кількість годин на ціле число.
5. Відібрати задачі відповідно до заданих умов. За замовчуванням задачі зі статусом `done` не враховуються в основному аналізі.
6. Обчислити кількість активних задач і загальну кількість годин.
7. Підсумувати години для кожного виконавця.
8. Визначити унікальних виконавців.
9. Відібрати задачі з пріоритетом `high`.
10. Впорядкувати результати для стабільного виведення.
11. Записати текстовий звіт у файл.
12. Повідомити користувача про результат або помилку.

Сортування результатів забезпечує детермінованість: за однакових вхідних даних звіт формується в однаковому порядку.

## 8. Обробка помилок

Для повідомлення про помилки вхідних даних створено власний виняток `DataError` у модулі `errors.py`.

Програма перевіряє такі ситуації:

- CSV-файл відсутній або недоступний;
- файл порожній або не містить заголовка;
- відсутні обов'язкові колонки;
- значення обов'язкового поля відсутнє;
- текстове поле містить лише пробіли;
- кількість годин не перетворюється на ціле число;
- кількість годин має від'ємне значення;
- виникає помилка під час читання або запису файлу.

Під час обробки помилок перетворення значень може використовуватися конструкція `raise ... from ...`, яка зберігає початковий виняток як причину нового. Це полегшує діагностику помилки.

CLI обробляє передбачені помилки даних і файлових операцій, виводить повідомлення про помилку та повертає ненульовий код завершення. У разі успішного виконання повертається код `0`.

## 9. Формування текстового звіту

Результат роботи програми записується у файл:

`reports/report.txt`

Для роботи з файлами використовуються `pathlib.Path` і контекстний менеджер `with`. Файл відкривається для запису в кодуванні UTF-8. Модуль формування звіту створює батьківські каталоги, якщо вони відсутні.

Приклад звіту для наданого набору даних:

```text
PROJECT TASKS REPORT
====================
Total active tasks: 6
Total hours: 26

HOURS BY ASSIGNEE
-----------------
Anna: 9 hours
Ivan: 4 hours
Oleh: 13 hours

UNIQUE ASSIGNEES
----------------
Anna, Ivan, Oleh

HIGH PRIORITY TASKS
-------------------
Website design | Anna | 5 hours | in_progress
API development | Oleh | 8 hours | in_progress
Fix login bug | Oleh | 2 hours | todo
Deploy application | Anna | 4 hours | todo
```

У наведеному прикладі задачі зі статусом `done` не включаються до загальної кількості активних задач і сумарних годин. Задачі з високим пріоритетом виводяться окремим списком відповідно до правил аналізу.

## 14. Академічна доброчесність і використання інструментів розробки

Під час захисту роботи потрібно бути готовою пояснити призначення модулів, алгоритм обробки даних, обробку помилок, тести й налаштування CI. Опис використаних інструментів відповідає фактичним діям, виконаним під час розробки.

## 15. Відповіді на контрольні запитання

**1. Для чого призначений формат CSV?**

CSV — текстовий формат для зберігання табличних даних, у якому значення полів розділяються спеціальним символом, найчастіше комою.

**2. Як прочитати CSV-файл у Python?**

Для цього можна використати стандартний модуль `csv` і клас `csv.DictReader`, який дає змогу звертатися до значень за назвами колонок.

**3. Навіщо перетворювати значення CSV до інших типів?**

Під час читання CSV значення зазвичай представлені текстом. Для арифметичних операцій кількість годин потрібно перетворити на цілі числа.

**4. Що таке список у Python?**

Список (`list`) — впорядкована змінювана колекція елементів, яка може містити значення різних типів.

**5. Що таке словник у Python?**

Словник (`dict`) зберігає пари ключ–значення й дає змогу отримувати значення за ключем.

**6. Що таке множина?**

Множина (`set`) — колекція унікальних елементів, яка не зберігає дублікати.

**7. Що таке list comprehension?**

Це компактний спосіб створення списку на основі іншої послідовності та, за потреби, умови фільтрації.

**8. Для чого використовують функції?**

Функції дають змогу розділяти програму на логічні частини, повторно використовувати код і спрощувати тестування.

**9. Що таке аргумент за замовчуванням?**

Це значення параметра функції, яке використовується, якщо під час виклику аргумент не передано.

**10. Для чого потрібен `*args`?**

`*args` дає змогу передавати довільну кількість позиційних аргументів у функцію.

**11. Для чого потрібен `**kwargs`?**

`**kwargs` збирає довільну кількість іменованих аргументів у словник.

**12. Що таке виняток у Python?**

Виняток — механізм повідомлення про помилку або іншу особливу ситуацію під час виконання програми.

**13. Для чого використовують `try` і `except`?**

Вони дають змогу перехоплювати й обробляти помилки, щоб програма могла вивести зрозуміле повідомлення або коректно завершитися.

**14. Що означає `raise ... from ...`?**

Цей синтаксис створює новий виняток із явним зазначенням початкового винятку як причини, зберігаючи інформацію для діагностики.

**15. Для чого потрібен контекстний менеджер `with`?**

Він гарантує належне завершення роботи з ресурсом, наприклад закриття файлу після завершення блоку.

**16. Для чого потрібен `pathlib.Path`?**

`Path` надає об'єктний інтерфейс для роботи зі шляхами до файлів і каталогів, зокрема для відкриття файлів і створення каталогів.

**17. Що таке модуль і пакет Python?**

Модуль — окремий файл Python, а пакет — структура, яка об'єднує пов'язані модулі в одному просторі імен.

**18. Для чого потрібен `pytest`?**

`pytest` — інструмент автоматизованого тестування Python-коду, який допомагає перевіряти правильність поведінки програми.

**19. Для чого потрібен `ruff`?**

`ruff` — інструмент статичного аналізу й перевірки стилю Python-коду, який також підтримує автоматичне форматування.

**20. Для чого потрібні Git, GitHub Actions і пакування?**

Git зберігає історію змін коду. GitHub Actions автоматизує перевірки в репозиторії. Пакування дає змогу створювати дистрибутиви, які можна встановлювати й поширювати.
